# E-Commerce Business Intelligence

## Project Overview
This project focuses on analysing an e-commerce business using data analytics to understand business performance, customer behaviour, product sales, payment preferences, and delivery performance.

## Business Problem
The company wants to use its historical e-commerce data to identify business trends, understand customer behaviour, evaluate product and seller performance, and make data-driven decisions.

## Project Objectives
- Analyse overall sales and revenue.
- Identify top-performing product categories.
- Understand customer purchasing behaviour.
- Analyse payment methods and preferences.
- Evaluate seller and delivery performance.
- Understand customer satisfaction through reviews.
- Build an interactive business intelligence dashboard.

## Tools and Technologies
- Python
- Pandas
- SQL
- Power BI
- Git and GitHub

## Dataset
Brazilian E-Commerce Public Dataset by Olist.

Source: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Project Roadmap
1. Business and data understanding
2. Data cleaning and exploratory data analysis
3. SQL-based business analysis
4. Python analysis and visualisation
5. Power BI dashboard development
6. Business insights and recommendations
